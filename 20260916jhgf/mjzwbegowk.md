# 我院中医科王芳革、王洋参与四川省胚胎与生殖遗传学会（SSER）中西医结合生殖医学专业委员会成立大会！

> 更新时间：2026-09-16 (UTC+8)

2025年8月9日上午，四川省胚胎与生殖遗传学会（SSER）中西医结合生殖医学专业委员会成立大会在成都中医药大学附属医院学术报告厅隆重召开。

我院中医科**王芳革**主任医师、**王洋**主治医师，作为四川省胚胎与生殖遗传学会第一届中西医结合生殖委员会委员参加会议，学习中西医治疗不孕症的前沿学术研究，对中医治疗不孕不育、复发性流产、反复助孕失败等疑难病症的个性化诊疗方案有了更深入的理解和思路。

会议云集国医大师刘敏如教授、中西医结合生殖医学著名专家全国名中医尤昭玲教授、不孕领域权威专家四川省名中医曾倩教授以及四川大学华西第二医院、四川省人民医院、四川省妇幼保健院等业内知名专家就中西医结合运用于生殖临床诊疗难题解决思路、生育力保护、生殖内分泌与不孕不育症诊疗进展及生殖研究等方面进行了精彩纷呈的授课和分享。

国医大师刘敏如教授就“与时俱进发展中医妇科生殖学”为题作主旨报告，为中医生殖临床提供了纲领性指导。

全国名中医尤昭玲教授讲授“IVF-ET中西医融合诊疗”，为更好实现中医妇科与助孕生育周期全周期融合提供宝贵诊疗经验。

我院中医科郑小艳、王洋主治医师作为《尤昭玲中医临证思辨录》的编委之一，在聆听尤教授临证经验中获得了新的感悟。

四川省名中医曾倩教授将不孕症的防治与中医治未病观点有机结合，为提早干预卵巢功能减退，争取获得优质卵子提供了治疗思路。

她分享的卵巢早衰病例尤为典型：患者多次取卵，每次获卵数少，没有可用胚胎，经中药调理后终获优质胚胎并成功分娩，生动印证了中西医结合的临床价值。

作为尤昭玲教授的学术传承人，曾倩教授对中医全周期助孕辅助生殖的独到见解，为与会者开辟了新的诊疗视野。

此次大会的召开不仅搭建了中西医结合生殖医学的高层次交流平台，更彰显了多学科协作攻克生殖难题的必然趋势。

正如专家所强调，生育力保护需贯穿生命周期全程，而中西医结合模式通过整合现代医学精准诊断与中医整体调理优势，正成为提升辅助生殖成功率、改善疑难病症预后的关键路径。

未来，随着中西深化应用，中西医结合生殖医学将持续为患者提供更个性化、全周期的健康解决方案，推动区域生殖健康事业迈向新高度。
